## Описание
Добро пожаловать в мое портфолио проектов по аналитике данных! Здесь собраны учебные проекты, демонстрирующие мои навыки работы с Python и анализом данных. Проекты созданы в рамках обучения на курсе Анатилик данных Яндекс Практикума.

Проекты по анализу данных демонстрируют умения:

1. Загрузка и предварительное знакомство с данными.
2. Предобработка данных, включая работу с пропущенными значениями и дубликатами.
3. Визуализация данных.
4. Исследовательский анализ данных.
5. Применения статистического анализа для проверки гипотез.
6. Планирование A/B-тестирования.
7. Формулирование выводов и рекомендаций на основе полученных и обработанных данных.


Проекты созданы в Jupyter Notebook.

Спасибо за интерес к моему портфолио! Буду рада получить ваши отзывы и предложения.
